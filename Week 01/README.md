# 📘 Week 01 - Introduction to Deep Learning

This week introduces the foundational concepts of **Deep Learning**, starting with the **Perceptron** — one of the simplest building blocks of a neural network.

---

## 📚 Modules

### Module 01: Introduction to Deep Learning and Perceptrons

Covers the basics of Deep Learning and introduces the Perceptron — the simplest model of an artificial neuron. Explains how inputs, weights, bias, and activation functions work together to produce an output.

### Module 02: How Perceptrons Learn – Intuition, Code, and Edge Cases

Explores how a Perceptron learns by updating its weights using the **Perceptron Learning Rule**. Includes code implementation and discusses cases where a Perceptron may fail, such as non-linearly separable data.

### Module 03: Decision Boundaries and Perceptron Learning

Focuses on how a Perceptron creates a **decision boundary** to separate different classes of data and how the boundary changes during learning.

## 🎯 Key Takeaways

- Understand the Perceptron as a foundation of neural networks
- Learn how weights and bias are updated during training
- Understand the Perceptron Learning Rule
- Visualize decision boundaries for binary classification
- Understand the limitations of a single-layer Perceptron
