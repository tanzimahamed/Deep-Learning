## 📘 Week 01 - Introduction to Deep Learning

This week introduces the foundational concepts of Deep Learning, 
starting with the Perceptron — the simplest building block of a 
neural network.

---

### 📚 Modules

### Module 01: Introduction to Deep Learning and Perceptrons
Covers the basics of Deep Learning and introduces the Perceptron — 
the earliest and simplest model of an artificial neuron. Explains how 
it takes inputs, applies weights, and produces an output using an 
activation function.

### Module 02: How Perceptrons Learn – Intuition, Code, and Edge Cases
Explores the learning process of a Perceptron in depth — how weights 
are updated using the perceptron learning rule. Includes hands-on 
code implementation and discusses edge cases where a simple 
perceptron may fail (e.g., non-linearly separable data).

### Module 03: Decision Boundaries and Perceptron Learning
Focuses on how a Perceptron creates a decision boundary to separate 
different classes of data, and how this boundary shifts as the model 
learns from training examples.
