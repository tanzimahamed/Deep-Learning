##  Week 01 - Introduction to CNN

This week introduces Convolutional Neural Networks (CNNs) — the core
architecture behind modern computer vision models.

---

###  Modules

### Module 01: Introduction to CNN
Introduces the fundamentals of Convolutional Neural Networks, explaining
how they differ from standard neural networks and why they are
particularly effective for image-based data.

### Module 02: Padding, Stride and Pooling in CNNs
Covers key CNN operations — padding (preserving spatial dimensions),
stride (controlling filter movement), and pooling (downsampling feature
maps) — and how each affects the output feature map.

### Module 03: CNN Project
A hands-on project applying CNN concepts learned so far to build and
train a convolutional neural network on a real dataset.

### Module 04: ADL Mid Term Exam
Mid-term assessment covering the Advanced Deep Learning (ADL) topics
studied up to this point.
